# Moonwell Curriculum
### A Behavioral Transformation System in Eight Modules

**Designer:** Jennipher Troup · [girlwithstarryeyes@outlook.com](mailto:girlwithstarryeyes@outlook.com) · Philadelphia, PA

> *A complete, standalone behavioral transformation workbook integrating Cognitive Behavioral Therapy, Gene Keys philosophy, Jungian shadow work, Stoic ethics, DBT, Internal Family Systems, Polyvagal Theory, and somatic practice into a single coherent protocol — with an ethical framework built into the architecture, not bolted on afterward.*

---

## What It Is

Moonwell is an 8-module curriculum for adults navigating patterns they’ve tried to change and haven’t been able to — not because they lack willpower, but because they’re using the wrong frame. It is built on a single premise: every entrenched pattern was once a brilliant adaptive response. The work is not elimination. It’s reclamation.

The curriculum is fully functional with pen and paper. Digital tools enhance but are never required. All core materials are free to access.

## Recursive Architecture

The curriculum is not linear — it spirals. Each module’s output directly feeds the next:

```
M0 (Ethics) → M1 (Truth Statement) → M2 (Shadow) → M3 (Unity Statement)
     ↑                                                        ↓
M7 (Sovereign Thesis) ← M6 (Action Plan) ← M5 (Integration) ← M4 (Narrative)
     ↓
  Adaptive Loop → redefines focus of next M1 cycle
```

Module 7 does not end the curriculum — it redefines the starting point of the next one. Regression is built into the architecture as a data event, not a failure state.

## Ethical Architecture

Five structural principles govern what the system will and won’t do:

**Informed Consent** — Full transparency about process, effort required, and realistic outcomes. The practitioner is a collaborator, not a subject.

**Harm Reduction** — Graduated challenge calibration: never exceeding 6/10 discomfort. Active screening for acute crisis. Identity threat monitoring.

**Cultural Humility** — No assumption of individualist values. Explicit collectivist adaptation. No financial barriers to core materials.

**Anti-Deficit Framing** — Prohibited: *“fix yourself,” “you’re broken.”* Required: *“your patterns protected you,” “reclaim power.”* Shame blocks change. Compassion enables it.

**Accessibility** — Minimum viable system: pen, paper, human. Free access to all core materials.
