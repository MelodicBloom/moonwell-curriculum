# Moonwell Adaptive System Specification

The Moonwell Curriculum is designed to pair with a behavioral tracking architecture that individualizes the protocol across five vectors. This document specifies that architecture.

---

## Individualization Vectors

### 1. Learning Style
- **Visual:** Diagram-heavy module guides, color-coded Gene Key mapping, illustrated somatic scan
- **Auditory:** Audio walkthroughs for all exercises, spoken mantra recordings, guided RAIN meditations
- **Kinesthetic:** Movement-based somatic scan, physical ritual objects for M5, walking practice for Coherence Protocol
- **Reading/Writing:** Full written module guides, extended journaling prompts, written dialogue formats

### 2. Cultural Context
- **Individualist adaptation (default):** "I" as the primary unit; personal sovereignty as the frame
- **Collectivist adaptation:** "We" as the primary unit; the family/community as the field of change; ancestor mapping integrated into Root Tracer (M2); Letter of Gratitude (M5) addressed to lineage, not only self

### 3. Technology Access
- **Full access:** Digital module guides, audio tracks, tracking app, video walkthroughs
- **Partial access:** PDF downloads only; audio tracks via mobile
- **No technology:** Complete paper-based system; all exercises function with pen and paper; facilitator-delivered audio instructions

### 4. Literacy Level
- All exercises have a plain-language version (Grade 6 reading level)
- Core concepts summarized in 1–3 sentences before elaboration
- Visual metaphors provided for all abstract concepts

### 5. Stress Tolerance
- Practitioner self-rates stress tolerance at intake (1–10)
- Module pacing adjusted: low tolerance = longer M0, extended M1 before M2
- Graduated challenge ceiling: no exercise exceeds 6/10 self-reported discomfort
- Distress protocol activated at 7/10: pause, somatic anchor, optional facilitator contact

## Neuroplastic Proxy Metrics

The system tracks four metric categories as proxies for neuroplastic change (direct measurement requires clinical neuroimaging; these are behavioral correlates):

### 1. Practice Consistency
- Days active per week (target: 5+)
- Module completion rate
- Protocol Card usage frequency (self-reported)

### 2. Self-Efficacy Ratings
- Pre/post rating for each module (1–10 scale)
- "How much do I believe I can navigate this pattern differently?" — measured before M1 and after each subsequent module
- Trajectory: consistent increase signals active rewiring

### 3. Behavioral Evidence Log
- Weekly log of specific, observable behavioral changes
- Format: "[Activation context] → [Old response] → [New response chosen] → [Outcome]"
- Minimum 1 entry per week; 3+ entries indicate active transfer from insight to behavior

### 4. Somatic Markers
- Self-reported body sensations at activation moments (before and after module sequence)
- Target: shift from high-activation (chest tightness, jaw tension, held breath) to lower-activation response over 8 weeks
- Not diagnostic — used as qualitative texture for the practitioner's own tracking

## Review Cadence

### Weekly Review (15 minutes)
Triggered after each 7-day period of active practice.

Review questions:
1. Which Intervention Ladder tiers were used this week?
2. Where did activation happen that I didn't catch in time?
3. What did the regression reveal? (New information, not failure)
4. Does anything in the Protocol Card need to be updated?

Output: Updated Protocol Card if needed; 1-sentence note to future self.

### Monthly Review (45 minutes)
Triggered at Day 30 of the cycle.

Review questions:
1. What has measurably changed in my behavior? (Behavioral Evidence Log)
2. What self-efficacy shift has occurred? (Pre/post comparison)
3. What does the Resonance Log reveal about where the Gift appeared?
4. Is the current Gene Key still the right focus, or has a new layer emerged?

Output: Decision on whether to continue current cycle or initiate next M1 with updated focus.

## Minimum Viable Implementation

The adaptive system functions fully without any technology:

| Function | Digital Implementation | Paper Implementation |
|---|---|---|
| Module guides | PDF / web app | Printed packet |
| Tracking | App / spreadsheet | Journal + weekly review sheet |
| Audio exercises | Audio files / streaming | Facilitator reads aloud |
| Metric tracking | Automated dashboard | Hand-drawn chart in journal |
| Review cadence | Calendar reminders | Physical calendar marks |

Every practitioner has full access to the complete system regardless of technological resources.
