# Module 1 — THE GROUND
**Anchor & Intercept**

> *Luminous Precision — quick, sharp, clinical.*

## Purpose

M1 intercepts the automatic pattern before it completes its loop. Most behavioral work fails because it tries to change a pattern that the practitioner hasn't yet clearly seen. The Ground creates the first clear seeing: not a judgment, not a story — a precise, layered description of what is actually happening.

## Framework: F1 — Cognitive Distortions Audit

Applied CBT (Beck). The practitioner identifies the active cognitive distortions operating in their presenting pattern:

- All-or-nothing thinking
- Catastrophizing
- Mind reading
- Emotional reasoning
- Should statements
- Personalization
- Filtering (magnifying negative, discounting positive)
- Jumping to conclusions

For each identified distortion, the audit asks three questions:
1. What is the observable fact (without interpretation)?
2. What story is being added to that fact?
3. What core belief does that story confirm?

## The Triple-Layered Truth Audit

The audit produces three separated statements:

**Layer 1 — Observed Fact:** What actually happened, stated in neutral, behaviorally specific language. No interpretation, no feeling word, no meaning.

**Layer 2 — The Story:** The meaning assigned to the fact. What it "means" about self, others, or the world.

**Layer 3 — The Core Belief:** The bedrock assumption the story confirms. Usually pre-verbal, pre-conscious, pre-relational. Often formed before age 7.

## Module Output

An **Integrated Truth Statement** — a single compound sentence in the form:

> *"When [Observed Fact], I tell myself [The Story], which confirms [The Core Belief]."*

This statement becomes the input for Module 2.

## Recursive Link

The Integrated Truth Statement feeds M2 as the starting point for constraint diagnosis and Shadow identification.

## Provenance

- CBT: Aaron Beck, *Cognitive Therapy of Depression* (1979)
- Stoicism: Epictetus, *The Enchiridion* (applied to the story/fact distinction)
